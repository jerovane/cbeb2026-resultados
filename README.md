# CBEB 2026 · Painel de resultados

Página de prestação de contas do XXX Congresso Brasileiro de Engenharia Biomédica (Fortaleza, 28/09 a 02/10/2026).

O acesso é por senha. O painel inteiro fica **cifrado** neste repositório (AES-256-GCM, com a chave derivada da senha por PBKDF2-SHA256, 600 mil voltas) e só é aberto no navegador de quem digita a senha. Sem ela, nem o código-fonte da página revela os dados.
